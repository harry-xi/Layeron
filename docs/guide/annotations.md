# 标注图层

标注（annotation）是掩膜的**矢量对应物**：它不写体素，而是在某一张切片上记录点、线段或封闭区域。标注与掩膜一样是分层管理的独立图层，可以叠加显示，并且属于**用户数据**——不会因为创建它的插件或脚本被卸载而消失。

每一层标注都可以以 JSON 单独保存为 `.la.json` 文件并重新载入，因此一份标注结果可以独立于体数据文件留存和传递。

## 标注与掩膜的区别

| | 掩膜 | 标注 |
|---|---|---|
| 数据形态 | 与体数据同尺寸的稀疏位图 | 每次标注只有几个顶点 |
| 维度 | 三维体素集合 | 局限在**一个切片**内 |
| 典型用途 | 分割、器官、任意二值集合 | 测量点、径线、感兴趣区域轮廓 |

因为标注只有几个顶点，它始终以矢量方式绘制：缩放切片不会让它变糊，移动十字线后也不需要重新栅格化整层。

## 标注管理器面板

`Tools → 标注管理器` 打开。每层的主体被压缩成两行：第一行是颜色、名称、标注数量、显隐与折叠按钮；第二行是 Alpha 只读显示与保存/删除。

| 控件 | 作用 |
|---|---|
| **Add Layer** | 新建一层标注 |
| **Load** | 从 `.la.json` 文件载入一层标注 |
| **Tool** | 选择 `Point`、`Line`、`Polygon` 或 `None` |
| **Cancel** | 放弃正在绘制、尚未完成的标注 |
| **Show** | 该层是否可见 |
| **Text** | 该层的标注名称是否叠加显示在切片图像上 |
| **Name / Color** | 图层名称与颜色；颜色选择器里的 **Alpha** 就是图层透明度 |
| **Save** | 把该层保存为 `.la.json` 文件 |
| **✕** | 删除整层 |
| **▾ / ▸** | 折叠或展开该层的标注列表 |
| 图层下方列表 | 该层的标注，可编辑名称、突出显示或逐条删除 |

新建标注会自动获得名称，按类型编号，例如 `Point 1`、`Point 2`、`Line 1`。名称可以直接在列表中修改；每层自己的 `Text` 复选框控制该层名称是否显示在切片图像上。`Text` 与折叠状态都只是视图状态，不会写入 `.la.json`。

颜色按钮打开的拾色器原生支持透明度：其中的 **Alpha** 就是图层透明度，面板上的 `α` 百分比只是只读显示，没有第二个透明度滑条。

每行标注左侧的 `◎` 按钮把该标注设为**突出显示**：它会以更粗的轮廓、更大的点或更明显的填充绘制，并位于同层其他标注之上；同一时刻只有一个标注处于突出状态，再次点击取消。

## 绘制

先在某个切片视图上确认当前切片，然后在面板里选择工具，用**左键**绘制：

- **Point**：单击一次落点。
- **Line**：单击起点，再单击终点。
- **Polygon**：依次单击顶点；到最后一个顶点时**双击**闭合区域。少于三个顶点时双击会取消。

绘制中的形状以虚线预览，完成后按图层颜色填充轮廓。`Cancel` 会丢弃未完成的顶点；切换到其他工具、切换活动层或更换数据也会丢弃未完成的顶点。

::: tip 与其他鼠标操作共存
右键仍然用于移动十字线；`Ctrl` + 左键仍然是掩膜画笔。只有在标注工具不是 `None` 时，左键才交给标注系统。
:::

## 坐标

标注顶点使用**切片自己的像素坐标**，与掩膜切片一致：

| 平面 | 水平轴 `U` | 垂直轴 `V` | 层号 |
|---|---|---|---|
| `XY`（轴位） | X | Y | Z |
| `XZ`（冠状位） | X | Z | Y |
| `YZ`（矢状位） | Y | Z | X |

插件与脚本创建标注的方式见[宿主服务](/plugin/services#标注-iannotationservice)。

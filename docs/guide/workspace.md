# 工作区

工作区是一个存放你**工作文件**的文件夹。它可以整体拷贝、备份、分享，在另一台机器上打开时内容一致。

## 目录约定

工作区内部的子目录布局由应用固定，而不是每个工作区自选：

| 目录 | 内容 | 归属 |
|---|---|---|
| `<工作区>/scripts` | 你的 C# 脚本（`.csx`） | 宿主固定创建 |
| `<工作区>/python` | 你的 Python 文件（`.py`） | Python 插件按需创建 |

`scripts/` 由宿主固定创建；`python/` 等语言目录由对应插件解析，宿主只提供工作区根目录。这样新增一种脚本语言不需要改宿主。

## 位置

| 项 | 位置 |
|---|---|
| 默认工作区 | `%LOCALAPPDATA%\Layeron\workspaces\Default` |
| 上次使用的工作区 | `%APPDATA%\Layeron\workspace.json` |

「上次使用哪个工作区」记录在应用状态中，因此工作区文件夹里始终只有你的工作文件。

## 切换工作区

`文件 → 工作区 → 打开工作区…` 选择一个文件夹；如果它不存在，会就地创建。菜单里还有"在资源管理器中打开"。

当前工作区的名字常显在状态栏右下角。

切换后，脚本列表会跟随新工作区；插件不受影响——插件来自插件目录，与工作区无关。

## 脚本的两个身份

工作区里的脚本与插件目录里的脚本**不是一回事**：

| 目录 | 身份 | 行为 |
|---|---|---|
| `<工作区>/scripts` | 你的工作脚本 | 被编辑器列出、编辑，在当前数据上运行；**不会**被自动激活为插件 |
| `<插件目录>/scripts` | 安装为插件的脚本 | 被发现并激活：其中的菜单 / 工具 / 贡献出现在应用里 |

**安装是一个明确动作**：把文件放进插件目录的 `scripts/`，再用 `插件 → 脚本 → 重新加载脚本` 刷新。仅仅保存在工作区里的脚本不会被执行。

详见 [C# 脚本](/guide/scripting)。

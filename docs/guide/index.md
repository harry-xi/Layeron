# 什么是 Layeron

Layeron 是一个面向**三维体数据**的桌面工作台，用 Avalonia 与 .NET 构建。它把浏览、测量、编辑与自动化放进同一个窗口：三个正交切片视图看数据，掩膜图层标注感兴趣区域，C# / Python 脚本与插件负责把重复的流程固化下来。

Layeron 可以按需扩展：数据格式、工具面板、菜单与体数据处理都能通过插件加入，而不需要改动应用本身。

## 能做什么

| 能力 | 说明 |
|---|---|
| 多平面浏览 | 轴位（XY）、冠状位（XZ）、矢状位（YZ）三个切片视图，共享十字准线与缩放 |
| 灰度显示 | 窗宽窗位调节、灰度直方图、单层数据值提示 |
| 掩膜标注 | 稀疏位图掩膜图层，可叠加、配色、调透明度、显隐 |
| 矢量标注 | 点、线段与切片内的封闭区域，分层显示，可缩放不失真 |
| 数据加载 | 内置 DICOM 序列读取，支持 8 位与 16 位体数据；插件可添加更多格式 |
| 3D 预览 | 从掩膜生成可交互的三维模型 |
| 脚本 | 用 C# 脚本做一次性计算并安装为插件；用 Python REPL/编辑器处理当前数据 |
| 可扩展 | 通过插件增加数据格式、工具面板、菜单与处理流程 |

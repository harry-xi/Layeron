# C# 脚本

脚本用来在当前数据上做**一次性计算**：读数据、把结果写回会话，跑完就走。

脚本与插件都能扩展应用，但用途不同：

| | 脚本 | 插件 |
|---|---|---|
| 形态 | 一个 `.csx` 源文件 | 编译后的程序集 |
| 适合 | 一次性计算、探索、批处理 | 长期驻留的功能 |
| 位置 | 工作区 `scripts/` 或插件目录 `scripts/` | 插件目录 |

## 打开脚本编辑器

`插件 → 脚本` 菜单提供三个入口，都会打开一个脚本窗口：

| 菜单项 | 说明 |
|---|---|
| 新建脚本 | 新建一个空白脚本文档 |
| 打开脚本… | 从磁盘打开一个 `.csx` |
| 重新加载脚本 | 重新扫描插件目录，让新安装的脚本生效 |

每个脚本窗口自带工具栏：**保存 / 另存为… / 打开… / 运行 / 取消**，以及一行状态与进度条。

保存与运行只出现在脚本窗口上，因为它们需要作用于某一个具体的脚本。

## 运行

- 运行的是编辑器里的**当前内容**（不必先保存），作用于**当前数据**。
- 计算在后台进行，长时间运行不会卡住窗口。
- 一次只运行一个脚本；点"取消"或关闭窗口即可中止。
- 编译错误与运行异常都会出现在日志窗口，应用不会崩溃。
- **掩膜、体数据与日志会保留**；脚本临时添加的菜单与面板在本次运行结束后消失。

## 脚本能做什么

- **读取当前数据**：体数据、十字准线位置、灰度直方图，以及任意区域的数值。
- **报告**：写日志、在状态行显示信息、报告进度、把结果作为一条日志条目输出。
- **写回会话**：添加掩膜图层、替换体数据。
- **扩展应用**：像插件一样添加菜单项与停靠面板，或向其他插件的扩展点贡献按钮。

完整的可用成员与签名见 [API 参考 → ScriptGlobals](/plugin/api-reference#scriptglobals)。

::: tip 数据可能已经改变
取数据时把数据与其版本一起取回（`Snapshot()`），就不会发布基于旧数据的掩膜。`AddMask` 时主卷若已被替换，只会往日志写一条警告，掩膜照常加入。
:::

## 安装为插件

把 `.csx` 放进**插件目录**的 `scripts/`（例如 `%LOCALAPPDATA%\Layeron\plugins\scripts\`，开发时用 `<应用目录>\plugins.dev\scripts\`），然后 `插件 → 脚本 → 重新加载脚本`。

安装后，脚本里的菜单与面板会像编译插件一样出现在应用里，并随该插件的卸载一起消失。

::: tip 两个身份
同一个 `.csx` 放在哪里决定了它是什么：工作区里的是**你的工作脚本**（只被编辑与运行），插件目录里的是**安装为插件的脚本**（会被激活）。保存本身不会让一段代码开始执行。
:::

# 数据的加载与查看

## 支持的体数据

Layeron 处理标量体数据，每个体素是 8 位（0–255）或 16 位（0–65535）无符号整数，覆盖了绝大多数医学与科学影像数据。

载入新数据会替换当前会话中的体数据；掩膜等按尺寸定义的标注会同步校验是否匹配。

## 加载数据

### 内置路径

| 菜单项 | 说明 |
|---|---|
| `文件 → 加载数据` | 打开 `.b3d` 体数据文件（gzip 压缩的自有格式） |
| `文件 → 从数据源加载 → DICOM 序列 (文件夹)` | 打开一个文件夹，读入其中的一个 DICOM 序列 |
| `文件 → 从图片创建` | 选一组图片，按顺序堆叠成一个体数据 |
| `文件 → 生成演示数据` | 生成一份合成的 8 位演示体数据 |
| `文件 → 生成 16 位演示数据` | 生成一份 16 位演示体数据 |
| `文件 → 保存数据` | 把当前体数据保存为 `.b3d` |

**DICOM 说明**：读取时按序列中各帧在空间中的位置排序，做 `raw × RescaleSlope + RescaleIntercept` 换算并截断到 `[0, 65535]`——也就是 CT 的 Hounsfield 单位。由于 CT 序列大致跨越 -1024…3000，而视图默认从元素类型的完整范围开始显示，打开后画面会偏暗：这正是窗宽窗位存在的意义。

一个文件夹里可能装着整个检查（多个序列）。读取器取第一个序列，遇到第二个序列就停止——两个序列不是一个体。

### 插件提供的数据源

`文件 → 从数据源加载` 会列出全部可用的数据源：内置读取器，以及**插件提供的格式**。两者在使用上没有区别。

详见[数据加载器](/plugin/loaders)。

## 保存数据

当前体数据可以用 `文件 → 保存数据` 保存为 `.b3d` 文件，之后用 `文件 → 加载数据` 重新打开。

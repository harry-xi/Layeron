# 界面与布局

主窗口是一个停靠（dock）式布局：三个切片视图占据中央文档区，工具面板分布在左右与底部边缘，菜单栏在顶部，状态栏在底部。

## 菜单

| 菜单 | 内容 |
|---|---|
| **文件** | 加载数据、从数据源加载（内置的与插件提供的）、保存数据、生成演示数据、生成 16 位演示数据、从图片创建、工作区 |
| **窗口** | 轴位 / 冠状位 / 矢状位视图、重置布局、设置 |
| **Tools** | 遮罩管理器、窗宽窗位、日志 |
| **插件** | 由插件添加的菜单项（每个插件在自己的子目录下） |

"从数据源加载"会列出当前可用的全部数据源（内置的与插件提供的），"工作区"列出当前工作区与切换方式。

## 三个切片视图

三个视图显示同一份数据，因此调节灰度范围会同时作用于它们。

| 视图 | 平面 | 含义 |
|---|---|---|
| **Axial**（轴位） | XY | 沿 Z 轴翻页 |
| **Coronal**（冠状位） | XZ | 沿 Y 轴翻页 |
| **Sagittal**（矢状位） | YZ | 沿 X 轴翻页 |

每个视图左上角显示当前层信息（平面、层号、体素尺寸等）。

### 鼠标操作

| 操作 | 行为 |
|---|---|
| 滚轮 | 前后翻页（切换当前层） |
| `Shift` + 滚轮 | 以指针位置为中心缩放 |
| 左键拖动 | 平移视图 |
| 左键双击 | 恢复“适应窗口”的缩放与平移 |
| 右键单击 | 把十字准线移到该点 |
| `Ctrl` + 左键拖动 | 在当前活动掩膜层上绘制笔刷 |

十字准线是三个视图共享的：在任一视图上移动它，另外两个视图会显示对应的位置。

## 工具面板

### 窗宽窗位

调节**所有视图**显示的灰度范围：

- **灰度下界** / **灰度上界**：两个滑杆，取值范围随数据元素类型变化（8 位为 0–255，16 位为 0–65535）。
- **重置**：恢复为元素类型的完整范围。

面板同时显示当前数据的灰度直方图，并在图上高亮标出当前选取的范围。

**下界对应全黑，上界对应全白**。16 位数据（例如 CT 的 Hounsfield 单位）默认打开时往往显得很暗，因为它跨越 -1024…3000 而视图默认从 0 开始——用窗宽窗位与直方图找到数据实际所在的位置即可。

### 遮罩管理器

见[掩膜图层](/guide/masks)。

### 日志

日志窗口：每条日志都有时间、级别、类别与消息，消息中的数值会作为独立字段一并显示，因此可以逐条查看、单独复制。

加载数据、切换工作区、插件加载与卸载、脚本运行结果都会写到这里；插件写入的日志也进入同一个窗口。

选中日志行后按 `Ctrl+C`，或右键复制。

## 设置窗口

`窗口 → 设置` 打开设置窗口，左侧是页面导航，右侧是内容。内置页面有：

| 页面 | 内容 |
|---|---|
| 常规 | 应用版本与占位说明 |
| 演示 | 声明式设置项的示例页 |
| 插件 | 插件目录位置、已加载插件与重载入口 |

插件可以通过扩展点向这个窗口追加自己的页面，见[设置页面](/plugin/settings)。

## 布局持久化

布局保存在 `%APPDATA%\Layeron\layout.json`，重启后自动恢复。`窗口 → 重置布局` 可以回到默认布局。

如果某个插件添加的面板在恢复时已不存在，该面板会被跳过，其余布局照常恢复。

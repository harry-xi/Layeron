# 掩膜图层

掩膜（mask）用来标注体数据中的感兴趣区域——分割结果、病灶、器官、任意二值集合。Layeron 的掩膜是**独立于体数据的图层**：它与主卷叠加显示、可以有很多层、每层有自己的名字、颜色与透明度。

## 掩膜与体数据

每一层掩膜都与它所标注的体数据**同尺寸**；把掩膜加到尺寸不符的数据上会被拒绝。

掩膜可以单独保存与载入，因此一份标注结果可以独立于体数据文件留存和传递。

## 掩膜管理器面板

`Tools → 遮罩管理器` 打开。

| 控件 | 作用 |
|---|---|
| **Add** | 新建一层空白掩膜 |
| **Load** | 从文件载入一层或多层掩膜 |
| **Copy** | 把当前活动掩膜复制为一个独立的新图层 |
| **Show** | 该层是否可见 |
| **Name** | 图层名称（可直接编辑） |
| **Color** | 图层颜色；拾色器里的 Alpha 就是叠加透明度 |
| **Remove** | 删除该层 |
| **Save** | 把该层保存到文件 |

面板顶部显示当前层数。**Load** 支持一次选择多个文件，因此一组掩膜可以一次恢复；**Copy** 复制的是当前活动层，副本有独立的像素，可继续单独绘制。

### 绘制

按住 `Ctrl` 并用左键在任一切片视图上拖动，会在**当前活动掩膜层**上绘制笔刷。

### 形态学与区域生长

示例插件 `layeron.maskmorphology` 提供“掩膜形态学”面板，对选中的掩膜做膨胀、腐蚀、开运算或闭运算。该插件还贡献一个**区域生长**切片工具：在工具箱中选择它，然后在切片上单击掩膜体素选择种子；工具会按掩膜自身的二值连通性，提取种子所在的一整块区域（6 或 26 连通），不读取体数据灰度。结果可以写入新图层，也可以覆盖源掩膜。

## 从掩膜生成 3D 模型

示例插件 `layeron.model3d` 贡献两个界面：

- **“3D 模型”工具面板**（插件菜单 → 工具）负责创建与管理：选择掩膜层、降采样倍数与重建方式，点击“生成模型”；
  “导入…”可以一次选择多个 glTF/GLB 文件。生成/导入的模型都会进入面板的模型列表，每一行都有自己的颜色选择器、
  显示开关、导出与删除操作。掩膜模型默认继承掩膜层颜色；导入模型改色会覆盖自带材质。工具条上的“清空”移除整个场景。
- **“掩膜 3D 模型”文档标签页**只负责显示：它会画出列表里所有可见的模型，首次生成时自动打开，之后可以一直开着做对比。
  拖拽旋转（向右拖，模型向右转）、`Shift`+拖拽平移、滚轮缩放（上滚放大）；单击掩膜表面可定位十字准线。
  相机按可见模型的整体范围取景。

::: tip GPU 渲染，但没有私有图形栈
3D 展示使用插件内的 Aura3D 引擎，通过 Avalonia 已经建立的 OpenGL 上下文出图——不初始化 Vulkan，也不需要插件自己维护光栅器。
:::

模型顶点坐标直接使用原始体数据的体素坐标：原点在采样盒角上，1 个世界单位等于 1 个原始体素。
因此同一个掩膜用不同降采样倍数生成时，模型占据同一位置（而不是各自居中），便于把模型上的点映射回体素；
导入的 glTF 则保留文件自带的坐标系。

在 3D 视图里**左键单击掩膜表面**，会把共享十字准线移到该点所在的体素，三个切片视图同时跳转。
拖拽仍是旋转，`Shift`+拖拽是平移；单击阈值是 4 DIP，拖动超过它就不会误触发定位。导入的模型不参与定位
（它不在体数据坐标系里）。

## 谁拥有掩膜

掩膜是**用户数据**：它由你创建、属于当前会话，可单独保存到文件；不会因为生成它的插件或脚本被卸载而消失。

插件与脚本读写掩膜的方式见[宿主服务](/plugin/services#掩膜-imaskservice)。

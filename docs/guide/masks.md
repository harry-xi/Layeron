# 掩膜图层

掩膜（mask）用来标注体数据中的感兴趣区域——分割结果、病灶、器官、任意二值集合。Layeron 的掩膜是**独立于体数据的图层**：它与主卷叠加显示、可以有很多层、每层有自己的名字、颜色与透明度。

## 掩膜与体数据

每一层掩膜都与它所标注的体数据**同尺寸**；把掩膜加到尺寸不符的数据上会被拒绝。

掩膜可以单独保存与载入，因此一份标注结果可以独立于体数据文件留存和传递。

## 掩膜管理器面板

`Tools → 遮罩管理器` 打开。

| 控件 | 作用 |
|---|---|
| **Add** | 新建一层空白掩膜 |
| **Load** | 从文件载入一层掩膜 |
| **Show** | 该层是否可见 |
| **Name** | 图层名称（可直接编辑） |
| **Opacity** | 叠加透明度，以百分比显示 |
| **Remove** | 删除该层 |
| **Save** | 把该层保存到文件 |

面板顶部显示当前层数。

### 绘制

按住 `Ctrl` 并用左键在任一切片视图上拖动，会在**当前活动掩膜层**上绘制笔刷。

## 从掩膜生成 3D 模型

示例插件 `layeron.model3d` 提供了"掩膜 3D 模型"文档标签页：它把选定的掩膜层转换成可交互的三维表面，与切片视图并列显示在中央文档区。

::: tip 纯 CPU 渲染
3D 展示使用插件内的 CPU 光栅化，不需要 GPU、Vulkan 或特定驱动；在无图形设备的机器上也能运行。
:::

## 谁拥有掩膜

掩膜是**用户数据**：它由你创建、属于当前会话，可单独保存到文件；不会因为生成它的插件或脚本被卸载而消失。

插件与脚本读写掩膜的方式见[宿主服务](/plugin/services#掩膜-imaskservice)。
